A ~1:37 chill, steady lofi loop chosen to match the game's calm, retro,
dark/mint aesthetic without distracting from learning.

In-game it loops at a low volume (0.25) with an on/off toggle button; the
on/off choice is remembered per browser.

To change the music:
  1) Easiest — replace this file (frontend/audio/music/loop.mp3) with any track
     you like, keeping the same filename/path. The game just loops this file.
  2) Or generate a self-authored chiptune loop instead:
     python3 build/generate_music.py   (writes loop.mp3; see that file's header
     for tweakable tempo/progression/volume). Note: running it overwrites the
     sourced track above.
