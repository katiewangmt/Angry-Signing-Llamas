Tech Stack
🔶

TensorFlow

Dense neural network with batch normalization, dropout, and L2 regularization. Classifies 63 landmark features into 26 ASL letters with high accuracy.

🔵

MediaPipe Hands

Google's ML pipeline extracts 21 3D hand landmarks per frame. Position and scale normalized for translation/rotation invariance.

🔴

OpenCV

Real-time webcam capture, frame processing, and UI overlay. Handles video I/O and rendering at 30+ FPS for smooth detection.

Quick Start
terminal
# 1. Install dependencies pip install tensorflow mediapipe opencv-python numpy scikit-learn # 2. Collect training data (press letter keys + SPACE to capture) python collect_data.py # 3. Train the model python train_model.py # 4. Run real-time detection! python detect.py
Model Architecture
model.py
Input(63) # 21 landmarks × 3 coordinates (x, y, z) → Dense(256) → BatchNorm → ReLU → Dropout(0.4) → Dense(128) → BatchNorm → ReLU → Dropout(0.4) → Dense(64) → BatchNorm → ReLU → Dropout(0.2) → Dense(26, softmax) # A-Z output
