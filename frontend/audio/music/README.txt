Background music: loop.mp3

Provenance: procedurally generated by build/generate_music.py (self-authored,
no third-party samples). Treat as CC0 / public domain — free to bundle and
redistribute.

It is intentionally calm and quiet — this game teaches ASL to children, so the
music should stay gentle and not distract from learning.

To change the music:
  1) Easiest — replace this file (frontend/audio/music/loop.mp3) with any track
     you like, keeping the same filename/path. The game just loops this file.
  2) Or edit the parameters at the top of build/generate_music.py
     (TEMPO / PROGRESSION / volumes) and run: python3 build/generate_music.py

In-game it plays at a low default volume with an on/off toggle button, and the
on/off choice is remembered per browser.
